DAILY INTELLIGENCE · SEP 12, 2026

Agents are becoming an enterprise runtime.

The strongest verified signals in this window point to the infrastructure around agents: long-horizon execution, enterprise control planes, retrieval infrastructure, and inference economics.

Research window: Sep 11, 10:00 AM → Sep 12, 10:00 AM ISTSignal: HighFocus: Agent infrastructure · Enterprise AI · Retrieval · Developer tooling

Research / intelligence

What actually changed

01 · Enterprise agents

Salesforce introduced job-ready Agentforce agents and a long-horizon runtime

Salesforce announced job-ready agents across sales, service, commerce, employee experience and back-office work. Its new runtime is designed for goals spanning days and weeks, with memory, durable execution and dynamic steering. Multi-Agent Orchestration is GA; Agent Optimizer is planned for October.

Why it matters: the system unit is moving from an agent that answers a request to an agent that owns a goal over time. Persistent state, checkpoints, changing context, approvals and recovery become core runtime primitives.

Source: Salesforce · release distributed Sep 11, 12:24 UTC.

02 · Enterprise AI harness

Salesforce positioned a shared AI control plane above individual agents

Salesforce introduced an Enterprise AI Harness around trusted context, agency, action, governance, security and models, plus an AI Control Plane for identity, lifecycle, evaluation, observability and cost management across first- and third-party AI.

Why it matters: enterprises are being pushed toward a shared boundary around many agents instead of separate infrastructure for every agent. Treat this as an architecture signal, not proof that the category is solved.

Source: Salesforce · Sep 11 publication confirmed by contemporary coverage.

03 · Retrieval infrastructure

Elastic launched a serverless vector database for large-scale AI retrieval

Elastic announced Elasticsearch Vector Database on Sep 11 at 13:45 EDT. It manages vector storage, indexing, embeddings and hybrid retrieval, supports text, image and multimodal vectors, and says Better Binary Quantization can reduce vector memory use by up to 32x.

Why it matters: retrieval infrastructure is becoming a managed primitive. The developer question shifts from “how do I build a vector stack?” to “what control do I actually need over retrieval?”

Source: Business Wire / Elastic · Sep 11, 13:45 EDT / 17:45 UTC.

04 · Inference infrastructure

AWS added prefix-aware routing to SageMaker Inference

AWS introduced prefix-aware routing so requests sharing a prompt prefix can land on the same instance and reuse KV cache. AWS reported up to 77% lower P50 time-to-first-token and up to 16% higher throughput on its Llama 3.1 70B test, with 1.3–1.9 ms routing overhead.

Why it matters: prompt caching is becoming a scheduler and routing problem, not just a model-serving setting. Where an agent request runs can change both latency and economics.

Source: AWS Machine Learning Blog · Sep 10, 21:58 UTC, inside this window.

Story 01 · Salesforce long-horizon agents

Understand / opinion

  • Explain why a week-long goal is a different system category from a one-shot agent.
  • Missing piece: durable execution may matter as much as reasoning quality.
  • Contrarian: the bottleneck in autonomous agents may become state management rather than intelligence.
  • Debate: should an agent keep pursuing a goal after the user stops interacting?
  • Prediction: durable long-horizon runtimes become standard agent infrastructure.

Build / experiment

  • 30 min: persistent goal + next-action loop.
  • 60 min: add checkpoints and resume-after-failure.
  • 90 min beginner build: a personal-project agent that remembers a goal and resumes tomorrow.
  • 1 day: miniature runtime with memory, scheduling, tools, approvals and kill switch.
  • Recreate the idea with ordinary LLM calls and a database.

Test / teach / apply

  • Stateless vs persistent agent benchmark.
  • Remove memory and measure repetition/failure.
  • Change requirements midway and test adaptation.
  • Tutorial: build a resumable worker.
  • Architecture: memory + durable execution + steering.
  • Business: agent-runtime infrastructure for teams that cannot build it themselves.

Top routes: 90-minute build, persistent-agent experiment, architecture breakdown, “state is the bottleneck” thesis, one-day runtime.
